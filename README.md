## 🚀 Featured Projects

### 🤖 AI Products & Agents

**[AutoPost](https://github.com/MAliMemon/AutoPost)** — A real, always-on content bot. Generates grounded posts from live RSS seeds via Groq, dedupe-checks them against real post history, routes drafts through a Telegram approve/reject/regenerate flow, and publishes on schedule to a real Mastodon account and Telegram channel.
`Python` `APScheduler` `Mastodon.py` `python-telegram-bot` `SQLite`

**[CallPilot](https://github.com/MAliMemon/callpilot)** — AI sales voice agent for a fictional solar company. Holds a natural conversation, qualifies leads, books real appointments via tool-calling against Postgres, and shows every call live on a dashboard. Runs entirely on the Groq free tier.
`Python` `Postgres` `Tool-calling` `Docker`

**[DealerChat](https://github.com/MAliMemon/dealerchat)** — Full-stack demo SaaS: an AI chatbot for a car dealership with RAG-grounded answers, vehicle recommendations, AI intent-scored lead capture, and a secure admin dashboard.
`Next.js` `TypeScript` `RAG` `Gemini/Claude`

**[DocsBrain](https://github.com/MAliMemon/docsbrain)** — RAG-powered Q&A over internal documents, with cited answers and a guardrail that declines instead of hallucinating. Async FastAPI + pgvector, streamed over SSE, provider-agnostic LLM layer.
`Python` `FastAPI` `PostgreSQL` `pgvector`

**[RepoAsk](https://github.com/MAliMemon/RepoAsk)** — A live Telegram bot ([@repoask_bot](https://t.me/repoask_bot)) that answers grounded, cited questions about any public GitHub repo by reading its README and docs in real time.
`Python` `Telegram Bot API`

**[ClauseCheck](https://github.com/MAliMemon/ClauseCheck)** — Analyzes SEC EDGAR contracts (or uploaded PDFs) into plain-English summaries, key terms, and cited risk flags.
`Python`

**[Civic RAG Chatbot](https://github.com/MAliMemon/civic-rag-chatbot)** — A domain-specific assistant for civic issue resolution (waste, water, municipal services), built on FAISS + sentence-transformers + Groq.
`Python` `Flask` `LangChain` `FAISS`

### 🛠️ Automation & Data Tools

**[LeadFinder](https://github.com/MAliMemon/LeadFinder)** — Real lead-generation CLI: finds businesses via OpenStreetMap, scrapes their sites for contacts, scores/cleans leads with Groq, dedupes against history, exports to CSV or Google Sheets.
`Python` `Overpass API` `Groq`

**[SheetFeeder](https://github.com/MAliMemon/sheetfeeder)** — Config-driven scraping pipeline: describe a site in YAML and it scrapes, cleans with pandas, validates with pydantic, dedupes, and upserts to Google Sheets or CSV.
`Python` `pandas` `pydantic`

**[FlowForge](https://github.com/MAliMemon/flowforge)** — Lightweight, provider-agnostic LLM workflow automation engine (Groq/Anthropic/mock) with YAML-defined workflows and an n8n export path.
`Python` `FastAPI` `PostgreSQL`

**[IRIS SLA Tracker](https://github.com/MAliMemon/iris-sla-airflow)** — SOC shift-and-SLA tracker for DFIR-IRIS cases. An Airflow pipeline polls cases, evaluates per-severity SLA clocks, emails analysts, and manages on-call handovers, paired with a Flask dashboard.
`Python` `Airflow` `Flask` `PostgreSQL`
