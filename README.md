## 🚀 Featured Projects

### 🧠 [DocsBrain](https://github.com/MAliMemon/docsbrain)
RAG-powered internal document Q&A app. Upload SOPs/policy docs, ask questions in plain English, get answers grounded and cited in the source text — with a guardrail that declines to answer instead of hallucinating when nothing relevant is found. Fully async FastAPI + SQLAlchemy 2.0, PostgreSQL with `pgvector` for semantic search, streamed responses over Server-Sent Events, and a provider-agnostic LLM layer (OpenAI / Anthropic Claude / Groq — swappable via one config value).

`Python` `FastAPI` `PostgreSQL` `pgvector` `Docker` `SQLAlchemy`

### 🏛️ [Civic Issues RAG Chatbot](https://github.com/MAliMemon/civic-rag-chatbot)
A domain-specific conversational assistant for civic issue resolution (waste management, water supply, and other municipal services), built on a RAG pipeline with a FAISS vector store, sentence-transformers embeddings, and Groq for fast response generation.

`Python` `Flask` `LangChain` `FAISS` `Sentence-Transformers`

### 🕸️ [Graph Visualizer with OS Concepts](https://github.com/MAliMemon/Python-Based-Graph-Visualizer-with-OS-Concepts)
A modular Python project for managing and visualizing graphs, built for an Operating Systems course — Tkinter GUI, dynamic graph operations, and visual output via matplotlib/networkx.

`Python` `Tkinter` `NetworkX` `Matplotlib`

### 🌐 [Lumiere Site](https://github.com/MAliMemon/lumiere-site) — [Live demo](https://lumiere-site-livid.vercel.app)
A deployed TypeScript frontend project.
